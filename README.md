# PISVA Portfolio — Screenshot Edition

A responsive, English-language portfolio site using the seven PISVA screenshots supplied by the project owner.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. No build tools or package installation are required.
3. Keep the `assets` folder beside `index.html`.

## Publish
Deploy the complete folder as a static site using Vercel or Netlify. The original PISVA application repository remains separate and private.

## Before publishing
- Review screenshots for any personal or sensitive information you do not want public.
- These supplied screens visibly include demo names, an email address in the family view, and health-related sample content. Replace or blur anything you do not want publicly displayed.
- Never upload `.env`, credentials, API keys, database exports, or private source code.

The PISVA logo mark in the header is cropped from the screenshot provided by the project owner. The main app previews use the original supplied screenshots; the gallery has animated transitions and clickable navigation.
